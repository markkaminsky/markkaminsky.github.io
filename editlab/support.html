Support

EditLab — help for people using the app and for App Review

What EditLab needs

  • A Mac running macOS 14 or later
  • Nothing else — no account, no sign-in, no subscription

Editing, repair, character animation, narration and export all run on your Mac. The only outbound request EditLab makes on its own behalf is the optional Director pass, and only if you have entered your own API key and clicked it.

How to get help

Email markkaminsky99@gmail.com.

Include: your macOS version, the EditLab version (menu EditLab → About), what you were doing, and whether the clip was camera footage or generated video. Please do not paste API keys.

In the app, press ⌘? for the built-in Help.

Common questions

  • A project opens with missing media. Projects point at your source files where they live. If you moved, renamed, or deleted a file after saving, put it back or import it again.
  • Repairs don’t look applied. Region erase, blur, patch and the face-continuity pass are baked in at export — check the exported file, not only the preview scrub.
  • Narration sounds robotic, or a voice is missing. EditLab speaks with your Mac’s installed voices. Add better ones in System Settings → Accessibility → Spoken Content → System Voice → Manage Voices, then reopen the voice picker.
  • Voice control does nothing. It needs Microphone and Speech Recognition permission (System Settings → Privacy & Security). Recognition runs on-device when your Mac supports it.
  • Director pass asks for a key. That feature is optional and off until you paste your own Claude API key. Your brief and clip timings are sent; your media never is.
  • Import warns about frame rate, silent audio, or color. That is import conforming telling you what it found in a generated clip — the clip still imports.
  • Export fails or the file is empty. Check free disk space and that the source media is still available, then export again to a folder you own (not a read-only volume).

App Review note

Sandboxed, no accounts, no network required to use the app. Microphone and speech recognition are used for voice control and narration recording. The Director pass field is user-configured and empty by default.
