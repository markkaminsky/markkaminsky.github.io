Support

EditLab Tracker — help for people using the app and for App Review

What EditLab Tracker needs

  • A Mac running macOS 14 or later, with a display of 1280 by 800 or larger
  • Nothing else — no account, no sign-in, no subscription

Composing, splitting, mixing and export all run on your Mac. The app makes no network requests.

How to get help

Email markkaminsky99@gmail.com.

Include: your macOS version, the EditLab Tracker version (menu EditLab Tracker → About), what you were doing, and the song file if you can share it.

Common questions

  • I dropped an audio file and got one instrument, not a kit. Files shorter than about twenty seconds load as a single sample. A full-length track goes to the splitter. To split a shorter file anyway, use Sample → Split a Track.
  • Some split sounds are named low, mid or high. The splitter names a sound by its role when it can tell; when it cannot, it names the sound by where it sits. Rename any sound in the instrument list.
  • Export WAV takes a while. The song is rendered offline. A long song with many effects can take about as long as the song itself. Export M4A is written in real time and produces a file about a tenth of the size.
  • The interface is small on a large display. Window → Text Size scales the whole app in steps up to 150%. ⌘+ and ⌘− step it from the keyboard, ⌘0 returns to normal.
  • Nothing plays. Check the mute and solo buttons on the channel strips and the monitor level slider in the transport.

Privacy

Nothing is collected. Full policy: Privacy Policy.

App Review note

Sandboxed, no accounts, no network required to use the app, and no network requests made. The outgoing-connections entitlement is present only because the WebKit view that hosts the interface needs it to start its helper processes. The optional assistant runs on the device using Apple’s FoundationModels framework.
